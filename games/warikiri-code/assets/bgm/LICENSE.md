## 変更内容

- 公式ページの試聴用MP3を、ゲーム内で扱いやすい英数字のファイル名へ変更しました。
- 音声波形の切り貼り・再エンコード・別音源との合成は行っていません。
- ゲーム内では音量を10%にし、ピコの説明中は3.5%へ下げてループ再生します。
- ほんばんではボス撃破ごとに0.05倍ずつ、最大1.30倍まで再生速度を上げます。ブラウザの音程補正を有効にし、約2秒かけて滑らかに変化させます。

OtoLogicが本ゲームを協力・後援・認証していることを示すものではありません。
