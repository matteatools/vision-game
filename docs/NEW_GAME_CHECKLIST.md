# 新ゲーム追加チェックリスト

作業前に[`SEO_AND_GAME_PUBLISHING_SPEC.md`](SEO_AND_GAME_PUBLISHING_SPEC.md)と[`GAME_DEVELOPMENT_GUIDE.md`](../GAME_DEVELOPMENT_GUIDE.md)を読む。

## ゲーム本体

- [ ] 正式名称と重複しないslugを決めた
- [ ] `games/{slug}/index.html`で最後まで遊べる
- [ ] れんしゅう、本番、結果、トップへ戻る動線が動く
- [ ] PC、スマートフォン縦・横、マウス、タッチで確認した
- [ ] 低学年向け主要画面をひらがな中心・短文にした
- [ ] ゲーム画面へSEO用長文を追加していない

## 正本データ

- [ ] `data/games.json`へ一件だけ登録した
- [ ] `published`と`sitemap`を設定した
- [ ] プレイURL、ガイドURL、各画像を設定した
- [ ] 子ども向け短文と大人向けガイド文を設定した
- [ ] ゲーム中に実際に行う活動と分類を設定した
- [ ] 関連ゲームを設定した
- [ ] 「見ることを使うゲーム」への掲載を実内容から判断した
- [ ] `isVisionTraining`は`false`にした（変更は制作者の新しい明示指示が必要）

## SEO

- [ ] プレイページ固有のtitleとdescriptionを設定した
- [ ] ガイドページ固有のtitleとdescriptionを設定した
- [ ] 効果・改善・能力向上を断定していない
- [ ] canonicalとOGP画像が正式URL・実在画像を指す
- [ ] 画像altは内容を簡潔に表し、装飾画像は空にした

## 生成と確認

- [ ] `scripts/build-site.ps1`を実行した
- [ ] トップページ用データへ反映された
- [ ] ガイド一覧とガイドページが生成された
- [ ] sitemap.xmlへ正式URLが追加された
- [ ] トップ → ガイド一覧 → ガイド → ゲームを通常リンクでたどれる
- [ ] `scripts/check-seo.ps1`がエラーなしで完了した
- [ ] ローカルサーバーで全公開ページ・画像・リンクを確認した

## 公開

- [ ] 変更ファイルと公開対象を確認した
- [ ] `資格/`の非公開資料が含まれていないことを確認した
- [ ] 明確な公開依頼を受けてからアップロードした
- [ ] GitHub Pages反映後に公開URLが200で応答することを確認した
- [ ] Search Consoleでsitemapとインデックス状況を確認した
