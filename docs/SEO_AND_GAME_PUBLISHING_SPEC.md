# SEO・ゲーム公開仕様

## 1. サイトの位置づけ

「めとあたまのゲームパーク」は、子どもも大人も遊べる、目と頭を使う無料Webゲームサイトである。「子ども専用」「知育サイト」「学習サイト」と限定して説明しない。

サイト設計では、子どもが自分で「みつけたい」「おぼえたい」「おいかけたい」「くらべたい」「かんがえたい」など、そのときにやりたいことからゲームを選べることを重視する。低学年が使う主要画面は、ひらがな中心・短い言葉・画像中心を維持する。

## 2. SEOとゲーム画面の分離

- ゲームルール、挙動、主要デザイン、スマートフォン操作をSEO目的で変更しない。
- ゲーム画面やトップの主要なゲーム選択部分へ、大人向けのSEO長文を追加しない。
- 各ゲームの検索用情報はhead内へ設定し、詳しい説明は静的なゲームガイドに分離する。
- 検索エンジンだけに見せる隠し文章は作らない。
- 通常の`a href`で、トップ → ガイド一覧 → 各ガイド → 各ゲームへ移動できるようにする。

## 3. 表現と効果に関する方針

説明できるのは、ゲーム中に実際に行う活動である。

- 画面の中から見つける
- 色や場所を覚える
- 動くものを目で追う
- 色・形・大きさ・向きを見比べる
- 数字の順番や合計を考える
- 線やパイプをたどってつなぐ

「能力が向上する」「集中力が鍛えられる」「記憶力が伸びる」「視力が改善する」「学力が上がる」「発達が促進される」などの効果を断定しない。

目から情報を受け取り、頭で考え、指や手で操作するという目・頭・体の連携はゲーム設計上の参考にしている。ただし、本サイトおよび各ゲームをビジョントレーニング®として提供・分類しない。この判断は`data/games.json`の`isVisionTraining: false`で明示する。

## 4. 正本データ

公開ゲーム情報の正本は[`data/games.json`](../data/games.json)である。次の情報をここで管理する。

- 正式名称、slug、公開状態
- プレイURL、ガイドURL
- タイトル画像、プレイ画像、OGP画像
- 子ども向け短文、大人向けガイド本文
- 分類、ゲーム中に行う活動、関連ゲーム
- プレイページとガイドページの固有title・description
- 「見ることを使うゲーム」への掲載状態
- ビジョントレーニング®として扱わない明示
- sitemap掲載状態

トップページ用の`data/games.generated.js`、ゲームガイド、各ゲームのhead、sitemap.xmlは`data/games.json`から生成する。

## 5. URLとページ

- トップ: `/vision-game/`
- about: `/vision-game/about/`
- ゲーム: `/vision-game/games/{slug}/`
- ガイド一覧: `/vision-game/guide/`
- 各ゲームガイド: `/vision-game/guide/{slug}/`
- 見ることを使うゲーム: `/vision-game/guide/miru/`

`classic.html`、テストページ、旧URL、下書き、非公開ゲームはsitemapへ入れない。

## 6. 各ページのSEO

### トップ

- title: `めとあたまのゲームパーク｜目と頭を使って遊ぶ無料Webゲーム`
- 固定ゲーム数をtitleやdescriptionへ書かない。
- WebSiteのJSON-LDは、実在する名称・URL・説明だけを記載する。

### ゲームページ

- titleは`ゲーム名｜めとあたまのゲームパーク`を基本とする。
- descriptionは、そのゲームで実際に行うことを固有の文章で説明する。
- canonical、OGP、Twitterカードを正しい絶対URLで設定する。
- 画面上へSEO本文を追加しない。

### ガイド

- 各ゲームに固有のtitle、description、本文を用意する。
- ページ上部と下部に実際のゲームへのリンクを置く。
- 関連ゲーム、ガイド一覧、トップへの通常リンクを置く。
- 構造化データは、確認できる事実だけをWebPage、CollectionPage、WebApplicationとして記載する。

## 7. 資格・商標資料

資格公開設定の正本は[`data/qualification.json`](../data/qualification.json)である。現在は資格の有効性と公開情報を確認済みのため`enabled: true`とし、有効期限、登録番号、正式商標マークの公開元・公開先を一元管理する。

- `資格/`の認定証や登録情報元ファイルを自動公開・OCR・加工しない。
- 公開するのは、設定で明示した正式商標マーク1点と、規約表示に必要な登録番号・有効期限だけとする。
- 公開商標マークは設定済みのSHA-256と照合し、非公開の元資料がない公開リポジトリ上でも改変を検出する。
- トップページの目立つ場所に、正式商標マーク、協会名、資格名、登録番号を表示する。
- `/vision-training/`を限定的なSEO検証ページとして公開し、トップとaboutからリンクする。
- 登録番号、期限、公開画像は設定ファイルへ人が明示した値だけを使う。
- 公開許可を確認できない画像や資料はコピーしない。
- 有効期限が未入力・期限切れ・確認不能の場合は、資格表示や専用ページを公開しない。
- 期限90日前、30日前、期限切れは検証スクリプトで警告・エラーにする。
- 資格情報が有効になっても、各ゲームをビジョントレーニング®と分類する変更は別途、制作者の明示判断を必要とする。

## 8. 生成と検証

正本データを更新したら次を実行する。

```powershell
powershell -ExecutionPolicy Bypass -File scripts/build-site.ps1
powershell -ExecutionPolicy Bypass -File scripts/check-seo.ps1
```

`build-site.ps1`は次を同期する。

- トップページ用ゲームデータ
- ガイド一覧と各ゲームガイド
- 見ることを使うゲームページ
- 資格・商標表示、正式商標マーク、`/vision-training/`（資格が有効な場合のみ）
- 各ゲームのtitle、description、canonical、OGP、Twitterカード
- sitemap.xml

`check-seo.ps1`は、必須項目、重複、ファイル欠落、canonical、noindex、画像、ガイドリンク、sitemap、robots、資格設定を確認する。

## 9. 公開前確認

- 全ゲームが起動する。
- トップの主要な選択体験とデザインが変わっていない。
- デスクトップ、スマートフォン縦・横で崩れない。
- 主要画面に漢字の長文が増えていない。
- ガイド一覧から全ガイドへ、各ガイドからゲームへ通常リンクで移動できる。
- 全公開URLが200で応答し、画像・リンク切れがない。
- titleとdescriptionが重複せず、canonicalが正式URLと一致する。
- sitemapに公開対象だけが掲載されている。
- 資格フォルダの未許可資料が公開されていない。
- トップの目立つ場所に正式商標マーク、協会名、資格名、登録番号が表示されている。
- 各ゲームをビジョントレーニング®として提供しない旨が明記されている。

## 10. 公開後の確認

Google Search Consoleでsitemap.xmlを送信し、次を8〜12週間の目安で確認する。

- ガイドとまとめページが登録されたか
- `/vision-training/`が登録され、「ビジョントレーニング®」関連の検索語で表示されたか
- サイト名以外の検索語で表示されたか
- 見つける、覚える、目で追う、数字、比較、パズル等の表示回数・クリック数・平均掲載順位
- ガイドページからゲームへ移動されたか（既存GA4の`guide_play_click`）
- 資格表示や専用ページから関連ページへ移動されたか（GA4の`vision_training_navigation`）

SEO検証では公開日を記録し、公開前28日と公開後の28日単位を比較する。8〜12週間で関連検索語の表示・クリックや専用ページからの回遊がほとんど確認できない場合は、`enabled: false`へ戻して再ビルドする。再ビルドによりトップ・aboutの資格表示、専用ページ、sitemap内URL、公開商標マークを生成対象から外す。公開済みの専用URLは、商標を含まない`/guide/miru/`への移行を検討する。

公開・アップロードは、明確な依頼があるまで実行しない。
